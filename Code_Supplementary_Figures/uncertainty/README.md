# Uncertainty calculations

- `01_quiet_area_uncertainty.py`: spatial quiet-fraction sensitivity at the
  fixed paper threshold of 0.1 Pa.
- `02_minimum_magnitude_uncertainty.py`: block bootstrap of the background
  noise plus the MQS S1133c magnitude uncertainty.

These scripts support the response to Reviewer 1 Major 3. They do not add a
new figure to the revised supplementary material.
